# Info
The info command will display information about your device as well as certain scan data.

## Usage
`info [-a <index>]`

#### Arguments
| Argument | Required/Optional | Description |
| -------- | ----------------- | ----------- |
| `no args` |                   | Display device information |
| `-a <index>` | Optional | Display [access point info](https://github.com/justcallmekoko/ESP32Marauder/wiki/view-ap-info) for AP at index |
