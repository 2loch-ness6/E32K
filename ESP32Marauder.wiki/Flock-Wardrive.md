# Flock Wardrive
Flock Wardrive pairs GPS data with sniff data in order to provide geolocation data for Flock Safety devices in a Wigle format. For additional information on Flock Safety cameras and their vulnerabilities, check [this blog](https://gainsec.com/2025/09/27/button-presses-to-shell-on-flock-safety-license-plate-cameras-over-wi-fi/). For other information regarding detection, check this blog post [here](https://www.ryanohoro.com/post/spotting-flock-safety-s-falcon-cameras).

## Menu Path
`Bluetooth`>`Sniffers`>`Flock Wardrive`

## CLI
This function is available for use via the [Marauder CLI](https://github.com/justcallmekoko/ESP32Marauder/wiki/cli). The following documentation describes command usage. The Airtag Sniff function can be stopped with [stopscan](https://github.com/justcallmekoko/ESP32Marauder/wiki/stopscan).

`wardrive -f`
