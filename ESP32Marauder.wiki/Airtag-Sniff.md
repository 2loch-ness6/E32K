# Airtag Sniff
Airtag Sniff is able to detect Apple Airtag devices which are advertising their presence using Bluetooth Low Energy. The information of the device including the advertisement payload is stored in memory for later use in spoofing attacks.

## Menu Path
`Bluetooth`>`Sniffers`>`Airtag Sniff`

## CLI
This function is available for use via the [Marauder CLI](https://github.com/justcallmekoko/ESP32Marauder/wiki/cli). The following documentation describes command usage. The Airtag Sniff function can be stopped with [stopscan](https://github.com/justcallmekoko/ESP32Marauder/wiki/stopscan).

### Usage
`sniffbt -t airtag`
