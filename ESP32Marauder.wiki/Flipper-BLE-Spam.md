# Flipper BLE Spam
Flipper BLE Spam is able to generate random data such as MAC address, Flipper Zero device name, and UUID and subsequently broadcast it as BLE advertisements.

## Menu Path
`Bluetooth`>`Bluetooth Attacks`>`Flipper BLE Spam`

## CLI
This function is available for use via the [Marauder CLI](https://github.com/justcallmekoko/ESP32Marauder/wiki/cli). The following documentation describes command usage. The Flipper BLE Spam function can be stopped with [stopscan](https://github.com/justcallmekoko/ESP32Marauder/wiki/stopscan).

### Usage
`blespam -t flipper`
