# sniffbt
Start anyone of the different types of Bluetooth sniffing. Using different switch arguments, you can specify filters to use while sniffing. If you do not specify a filter, it will default to sniffing all Bluetooth devices.

## Usage
`sniffbt [-t] <airtag/flipper>`

#### Arguments
| Argument | Required/Optional | Description |
| -------- | ----------------- | ----------- |
| `-t` | Optional| Specify sniffing for either [Airtags](airtag-sniff) or [Flipper Zero](flipper-sniff) |
