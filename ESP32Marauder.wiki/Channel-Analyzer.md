# Channel Analyzer
Displays the real-time frame rate for all detected WiFi frames in range on an historical graph. 

Frame density is represented by vertical cyan lines which make up the graph data. The maximum value currently displayed on screen is represented by a horizontal green line. The average value of all values on screen is represented by a horizontal orange line. Changes in WiFi channels are delineated by a vertical red line placed on the graph at the time of the channel change.

While the analyzer graph is displayed, the `UP` and `DOWN` buttons/switches may be used to increase or decrease the current channel.

The analyzer can be exited with a center click of your menu buttons or touching the screen (for touch-enabled hardware).

Channel Analyzer does not save PCAP data.

## Menu Path
`WiFi`>`Sniffers`>`Channel Analyzer`
