# Bluetooth Analyzer
Displays the real-time BLE beacon rate for all detected BLE beacon frames in range on an historical graph. 

Frame density is represented by vertical cyan lines which make up the graph data. The maximum value currently displayed on screen is represented by a horizontal green line. The average value of all values on screen is represented by a horizontal orange line.

The analyzer can be exited with a center click of your menu buttons or touching the screen (for touch-enabled hardware).

## Menu Path
`Bluetooth`>`Sniffers`>`Bluetooth Analyzer`
